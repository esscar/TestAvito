# Автотесты для API микросервиса Авито

Проект содержит автоматизированные тесты для проверки API микросервиса объявлений. Покрыты позитивные и негативные сценарии, проверки безопасности, а также граничные значения и валидация данных. 

**Стек:** Python 3, `pytest`, `requests`.

---

## Структура проекта

```text
├── tests/                  - директория с логическими модулями автотестов
│   ├── test_e2e.py         - e2e сценарии (жизненный цикл, списки, статистика)
│   ├── test_security.py    - проверки безопасности и доступов (IDOR, токены, подмена ID)
│   └── test_validation.py  - негативные проверки (валидация полей, типы данных, XSS)
├── conftest.py             - фикстуры (динамическая авторизация, teardown-очистка базы)
├── test_data.py            - тестовые данные (payload-ы и граничные значения)
├── BUGS.md                 - баг-репорты найденных дефектов на стенде
├── TESTCASES.md            - подробное описание 15 тест-кейсов
├── requirements.txt        - список зависимостей проекта
└── README.md               - описание проекта и инструкция по запуску 
```
Инструкция по запуску
---------------------

**1\. Клонирование и переход в папку проекта** Если проект загружен через Git, откройте терминал и перейдите в папку с проектом.

**2\. Создание и активация виртуального окружения**

```
python -m venv .venv  
Для Windows:  
.venv\\Scripts\\activate  
Для Mac/Linux:  
source .venv/bin/activate
```
3\. Установка зависимостей
```
pip install -r requirements.txt
```
**4\. Запуск автотестов** Для запуска всех тестов с подробным выводом выполните команду:
```
pytest -v
```
Результаты тестирования
-----------------------

*   Всего реализовано **15** независимых тест-кейсов.
    
*   Тесты полностью изолированы: перед каждым прогоном динамически создается новый пользователь, после тестов реализован механизм очистки (удаление созданных объявлений).
    
*   В ходе тестирования API выявлено несколько критических и логических дефектов. Подробное описание и шаги воспроизведения находятся в файле **`BUGS.md`**.
